# 🛒 বাজারদর (BazarDor) - Smart Grocery Price Intelligence & Basket Optimizer
> **বাংলাদেশের শীর্ষ অনলাইন সুপারশপগুলোর (Chaldal, Shwapno, Pandamart, Meena Click) লাইভ পণ্য দর তুলনা ও বাস্কেট সেভার প্ল্যাটফর্ম।**

`বাজারদর (BazarDor)` একটি আধুনিক, মোবাইল-অপ্টিমাইজড ও ডেস্কটপ-প্রিমিয়াম ওয়েব অ্যাপ্লিকেশন যা ভোক্তাদের বিভিন্ন অনলাইন সুপারশপের পণ্যের বর্তমান লাইভ দাম এক ক্লিকে তুলনা করতে এবং বাজারের ব্যাগে সর্বনিম্ন খরচে কেনাকাটা করতে সাহায্য করে।

---

## ✨ মূল ফিচারসমূহ (Key Features)

1. **রিয়েল-টাইম লাইভ প্রাইস ইঞ্জিন (Live Supermarket Scraper & API):**
   * চালডালের অফিসিয়াল ক্যাটালগ এপিআই থেকে সরাসরি রিয়েল-টাইম লাইভ মূল্য, MRP ও স্টক স্ট্যাটাস ফেচ করে।
   * প্রতি ৩০ মিনিট পর পর ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে দাম আপডেট হয় এবং ডিস্কে ক্যাশ থাকে।
   * ফ্রন্টএন্ডে লাইভ স্ট্যাটাস ইন্ডিকেটর ও এক-ক্লিকে "লাইভ রিফ্রেশ" বাটন।

2. **মাল্টি-স্টোর লাইভ কম্প্যারিজন ও সরাসরি লিঙ্ক:**
   * **Chaldal**, **Shwapno**, **Pandamart**, এবং **Meena Click**-এর পণ্যের দাম পাশাপাশি তুলনামূলক বিশ্লেষণ।
   * প্রতিটি পণ্যে **সর্বনিম্ন দর (Lowest Price)** এবং **সেরা স্টোর ব্যাজ** অটোমেটিক হাইলাইট।
   * প্রতিটি স্টোরের নামের পাশে ক্লিকযোগ্য সরাসরি লিঙ্ক (Direct Store Links) — ব্যবহারকারী চাইলে সরাসরি সেই স্টোরের পণ্য পেজে চলে যেতে পারেন।

3. **স্মার্ট বাস্কেট অপটিমাইজার (Smart Bag Optimizer):**
   * ব্যবহারকারী তার পুরো বাজারের ব্যাগ তৈরি করতে পারেন।
   * **সেরা একক দোকান (Best Single Store):** যেখান থেকে পুরো অর্ডার দিলে ডেলিভারি ফি সহ মোট খরচ সবচেয়ে কম হয়।
   * **স্মার্ট স্প্লিট সেভার (Smart Split Cart):** যদি ২টি স্টোর থেকে ভাগ করে কিনলে অতিরিক্ত ডেলিভারি ফি দিয়েও মোট খরচ কমে, তবে সেই সুপার সেভিং ডিল দেখায়।
   * ডেলিভারি চার্জ ক্যালকুলেটর (ফ্রি ডেলিভারি থ্রেশহোল্ড সহ)।

4. **স্লাইড-ওভার ব্যাগ ড্রয়ার (Slide-Over Drawer):**
   * হেডারের "আমার ব্যাগ" বাটনে বা মোবাইলের ফ্লোটিং বারে ক্লিক করলে ডানপাশ থেকে মসৃণ স্লাইড-ওভার ড্রয়ার ওপেন হয়।

5. **প্রিমিয়াম রেসপনসিভ ডিজাইন (Mobile & Desktop First):**
   * **মোবাইল:** পাশাপাশি ২টি করে প্রোডাক্ট (`grid-cols-2`) সহজে ব্রাউজিং।
   * **ডেস্কটপ:** প্রশস্ত গ্রিডে এক লাইনে কমপক্ষে ৪টি করে প্রোডাক্ট (`xl:grid-cols-4`)।
   * কোনো কৃত্রিম ফোন ফ্রেম ছাড়া পিওর ন্যাচারাল ওয়েব অ্যাপ এক্সপেরিয়েন্স।

6. **দ্বিভাষিক সমর্থন (বাংলা ↔ English):**
   * হেডারে এক ক্লিকে সম্পূর্ণ ওয়েবসাইট বাংলা অথবা ইংরেজিতে পরিবর্তনের সুবিধা।

7. **অথেনটিকেশন ও সেভড ব্যাগ (Firebase Ready):**
   * ফোন নম্বর ও গুগল লগইন আর্কিটেকচার (Firebase Auth রেডি)।
   * লগইন করা ব্যবহারকারীরা তাদের বাজারের ব্যাগ সেভ করে রাখতে পারেন।

8. **পেমেন্ট পার্টনার অফার ও টিসিবি দর:**
   * বিকাশ (10%), নগদ (12%), সিটি ব্যাংক এমেক্স (15%) ভাউচার ক্যালকুলেটর।
   * দৈনিক টিসিবি ও কাঁচাবাজারের পাইকারি দর সূচক।
   * হোয়াটসঅ্যাপে এক ক্লিকে পুরো ব্যাগ শেয়ারের সুবিধা।

## 🚀 কীভাবে চালাবেন (How to Run)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ব্যাকএন্ড সার্ভার চালু করুন (Port 5000):
```bash
npm run server
```

### ৩. ফ্রন্টএন্ড ডেভেলপমেন্ট সার্ভার চালু করুন (Port 5173):
```bash
npm run dev
```

ব্রাউজারে ওপেন করুন: `http://localhost:5173`

### ৪. প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

* **Backend:** Node.js, Express.js, CORS
* **Data Sources:** Live Chaldal Production Catalog API, TCB Daily Index
* **Auth:** Decoupled Architecture (Ready for Firebase Authentication)
